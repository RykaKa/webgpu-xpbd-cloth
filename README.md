# XPBD Cloth Simulation on WebGPU

Простая модель симуляции ткани методом **Extended Position Based Dynamics (XPBD)** 
на **WebGPU**. Реализация без сторонних рендер-движков — только чистый JavaScript, 
HTML, CSS и WGSL.

## Что реализовано

- Сетка ткани 20×20 ячеек (441 вершина), разбитая на треугольники.
- **4 угловые вершины** закреплены в пространстве.
- **Центральная вершина** перемещается по закону синуса в вертикальном направлении — 
  от неё распространяются волны по всей ткани.
- **Чекбокс «Включить гравитацию»** — включает/отключает силу гравитации, 
  направленную вниз.
- Все вычисления физики выполняются в **compute-шейдерах** на GPU.
- Реализован **Gauss-Seidel с раскраской ограничений** (8 групп) — устраняет 
  гонки при параллельном решении ограничений.

## Технологии

- WebGPU
- WGSL (WebGPU Shading Language)
- JavaScript (ES-модули)
- HTML / CSS

## Как запустить

Требуется Node.js (v18+) и браузер с поддержкой WebGPU — **Chrome 113+** 
или **Edge 113+**.

Установите зависимости:

    npm install

Запустите локальный сервер:

    npm start

Откройте в браузере:

    http://localhost:3000

## Структура проекта

- `index.html` — разметка страницы, canvas, чекбокс гравитации.
- `cloth.js` — вся логика: генерация ткани, шейдеры, инициализация WebGPU, 
  цикл рендеринга.
- `package.json` — зависимости и скрипт `npm start`.

## Параметры симуляции

- `GRID_N = 20` — количество ячеек по каждой оси.
- `CLOTH_SIZE = 1.0` — размер ткани в метрах.
- `SUBSTEPS = 20` — субшагов XPBD на кадр.
- `COMPLIANCE = 1e-5` — обратная жёсткость ткани.
- `DAMPING = 0.99` — коэффициент демпфирования скорости.
- `GRAVITY_Y = -9.81` — ускорение свободного падения, м/с².
